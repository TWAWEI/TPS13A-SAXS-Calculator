## 效能／體驗決定

1. **預覽的 q 網格**：有作用中資料時用該資料中**有限且 > 0** 的 q（其餘點不送，否則 q ≤ 0 的列會讓「N 點無法計算」永遠掛著）；沒有資料時用 1e-3–1 Å⁻¹ 對數 200 點（與 G1 相同）。
2. **昂貴模型的預覽降點與暫停**：估計量 `cost = nq × mesh × classWeight`，`mesh`＝已展開且寬度 > 0（或被勾選擬合）的 PD 參數其 npts 的乘積；`classWeight`＝1（1D 需要取向平均的 `cylinder`、`core_shell_cylinder`、`ellipsoid`、`flexible_cylinder`）或 0.01（其餘）。依據：M2 瀏覽器實測 400 點——sphere＋schulz 80 點 0.4 ms（12.5 ns／點）、cylinder 35 點 24 ms、35×35 為 755 ms（約 1.5 µs／點），兩類相差約 120 倍（規格 §11）。
   - `cost > PREVIEW_BUDGET`（150 000，圓柱類約 230 ms）時，預覽只取 `max(50, floor(PREVIEW_BUDGET / (mesh × classWeight)))` 個點：對預覽 q 的索引等距抽樣，必含首尾。此時圖區標「預覽以 N 點計算」。
   - 降點後的 cost 仍 > `PREVIEW_PAUSE_COST`（1 300 000，照同一個成本模型約 2 秒；例：三個 35 點 PD 的圓柱類）時，**即時預覽暫停**：不自動送出，圖區標「多分散網格過大，即時預覽已暫停」，並顯示「更新曲線」按鈕（`#sfPreviewNow`），按了才以降點後的網格算一次。
   - 擬合與擬合後的曲線永遠是全部點。未實測的三個重模型由 Task 14 量測並回報，數字差很多就調 `classWeight`（寫進完成紀錄）。
3. **debounce 150 ms＋latest-wins**（`SasFitWorkerClient.evaluate` 已有，`js/sasfit-worker-client.js:15-17`）；送出後 300 ms 還沒回來才顯示「計算中…」（規格 §4.10），回來即清除。**擬合開始時取消尚未觸發的 debounce 計時器，擬合進行中不送預覽**（Worker 的擬合迴圈是同步的，排隊的 evaluate 要等擬合結束），此時參數表、模型選單、範圍與資料清單的操作全部停用，只有「停止」與看圖的操作（顯示勾選、圖模式、錯開、分段切換）可用。
4. **不做「閒置後以全部點重算」**：重模型全部點要 1.5 秒以上，期間 Worker 被占住，下一次輸入的預覽會被拖慢（未決問題 a4）。
5. **參數表不整張重繪**：只有在模型／S(Q)／低 Q 冪律／PD 展開收合改變與擬合結束時才以 `innerHTML` 重建；使用者打字時只更新狀態、該欄的錯誤文字與 `aria-invalid`，否則每按一鍵焦點就掉。
6. **誤差棒自己畫**：站上沒有誤差棒外掛（`index.html:35-46` 只有 chart.js、hammer、zoom、annotation），也不為它新增 CDN。`sasfit-plots.js` 內寫一個 Chart.js 行內外掛（`afterDatasetsDraw`），顏色讀該 dataset 已被 `ChartTheme` 寫好的 `borderColor`（`js/chart-theme.js:119-124`），所以沒有顏色字面值、主題切換時自動跟著換（`chart-theme.js:205-213`）。**只畫作用中資料的誤差棒**（疊圖時其他組畫了只會糊成一片，也省繪製時間）。
7. **擬合範圍外的灰色區**用 annotation 外掛的兩個 box（`xMax: qMin` 與 `xMin: qMax`，`borderWidth: 0`）。現有調色盤沒有中性的區域色（`region`／`regionAlt` 是珊瑚與橘，`chart-theme.js:33-34`），在 `js/chart-theme.js` 兩個調色盤各加一個角色 `outOfRange`（中性半透明；色碼字面值本來就只准寫在這個檔）。這是本里程碑對 `chart-theme.js` 唯一的修改。
8. **疊圖**：一次載入很多檔時（序列資料）預設只勾選前 8 個「顯示」，其餘載入但不畫；作用中資料一定畫。系列色依資料在清單中的序號取（`tpsSeries`）。**每組資料的模型曲線與它的資料點同一個 `tpsSeries`、畫實線，作用中資料的點較大、線較粗，線畫在點之上**（dataset 的 `order` 較小者在上）。第 9 個起重用顏色：線由 `ChartTheme` 自動改虛線（`chart-theme.js:60-78`，規格 §5.6），點另以 `pointStyle` 區分——第 `floor(序號 / 8)` 輪依序用 `circle`、`rect`、`triangle`、`rectRot`。
9. **M4 的部分不放佔位**：序列分段、3D 區、匯出與「送進 IUCr」按鈕在 M3 完全不出現。停用而沒有作用的控制項會讓現場使用者以為功能壞了，也會讓 axe 與 markup 區段測試多一批之後還要改的 id。分段控制在 M3 是三段。
10. **主圖與殘差圖共用 x 軸**：縮放／平移只在主圖上操作，`onZoomComplete`／`onPanComplete` 把主圖的 x 範圍寫到殘差圖後更新；殘差圖自己不開縮放。「重設縮放」兩張一起重設。**兩張圖的 y 軸設相同的固定寬度**（`scales.y.afterFit = scale => { scale.width = SasFitPlotData.Y_AXIS_WIDTH; }`，72 px；函式在 `ChartTheme.colorize` 的拷貝中保留參照），繪圖區左緣才對得齊。
11. **進度的朗讀節流**：畫面上的步數與 χ²ᵣ 每個被接受的步都更新；`aria-live` 區域最多每 1 秒更新一次，結束時一定更新。圖區的狀態文字由一個純函式組出（`SasFitHints.plotStatus`）；「計算中…」只寫在畫面上，不進朗讀區。
12. **瀏覽器冒煙測試另開一個檔** `tools/sasfit/smoke_ui.py`，重用 `smoke_browser.py` 的伺服器與報告工具（`smoke_browser.py:36-79、207-243`）；原檔已 366 行，再加 UI 流程會超過 800 行。
13. **大檔的顯示抽點**：單組資料超過 `SasFitPlotData.DISPLAY_MAX_POINTS`（5 000）點時，顯示用等距抽點（步長 `ceil(n / 5000)`，必含首尾）；擬合、殘差的計算與 FitResult 永遠用全部點。抽點生效時圖區標「點數較多，圖上每 k 點顯示 1 點（擬合仍使用全部點）」。
14. **讀檔**：先依清單剩餘容量（上限 500 個檔）截掉多出的檔並提示，再**逐一依序**讀取與解析（不 `Promise.all`），超過大小上限的檔不讀。

**解析規則（實作與測試都照這裡）：**
- 前處理：開頭的 U+FEFF 去掉；以 `/\r?\n/` 分行。
- **官方檔判定**：第一個非空行含 `Data Collection Mode`；前 60 行內有一行符合 `/^\s*Single Frame Time\s*:/`；它的下一行符合 `/^\s*Q\s+I\s+ERROR\b/`；資料從再下一行開始。**不寫死 25 或 27 行**。任一條不成立 → 走一般檔規則。
- 官方檔頭欄位**以說明文字找**：`idx = line.indexOf(標籤)`，值＝`line.slice(0, idx).trim()`（不依賴 TAB）。幀時間用 `/Single Frame Time\s*:\s*([-+.\deE]+)/`。
- 官方資料列：以空白切 token；恰為 `['000','000','000']`（比字串，不比數值）＝佔位列，不進陣列、計入 `notes.placeholders`；否則要 ≥ 3 個數值 token（前三個為 q、I、σ；有第 4 個時讀進 `dq`——檔頭第 25 行設為 1 時的版面未經驗證，見未決問題 b1）。
- **數值 token**：嚴格符合 `/^[+-]?(?:\d+\.?\d*|\.\d+)(?:[eEdD][+-]?\d+)?$/`（`D` 指數當 `E`）；另外接受 `nan`、`inf`、`+inf`、`-inf`、`infinity`（不分大小寫）為非有限值。**不得直接用 `Number()` 判斷**——`Number('')` 是 0、`Number('0x10')` 是 16。
- **一般檔**：空行、`#`、`;` 開頭的行、第一個非空白字元不是數字／`+`／`-`／`.` 的行略過（計入 `notes.skipped`）。分隔符**每個檔決定一次**，看第一個候選資料行：含 `;` → 分號；否則含 `,` → 逗號；否則空白（含 Tab）。token 去頭尾空白；空 token 是錯誤。分隔符是分號或空白而 token 形如 `數字,數字` → 該行的訊息為「不支援小數逗號，請改用小數點」。欄數＝第一個資料列的欄數（必須是 2–4）；其他列欄數不同或有非數值 token → 列入 `issues`（附行號）、不進陣列。
- **排序**：有限的 q 若不是非遞減，依 q 穩定排序並設 `notes.sorted`；比較函式必須是全序——有限值升冪、非有限的 q 一律排在最後（不得寫成 `a - b`）。重複的 q 保留。
- **清理只標記不刪點**：I < 0、σ＝0、非有限值的列都留在陣列裡（只有佔位列與解析不了的行不進陣列）。
- 上限：點數 > `MAX_POINTS` → `dataset === null`。檔案大小由 DOM 層在讀取前檢查（Task 11）。
